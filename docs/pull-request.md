# Milestone 4: Monster Encyclopedia & Evolution Discovery

Players can now collect all ten original monsters in a responsive React encyclopedia. Actual drops and successful merges unlock creatures once, while previews and texture generation stay locked. The journal shows pixel sprites or anonymous silhouettes, progress, elemental attributes, evolution levels, original lore, and three persistent achievements. The first three display names are now Spriggle, Cindlet, and Dewble; stable keys, art, evolution order, radii, and scoring are unchanged.

A typed React/Phaser bridge sends appearances and journal commands with lifecycle cleanup. Opening the journal freezes physics, tweens, input, cooldown, and overflow timing; closing preserves the prior pause/game-over state. New discoveries queue dismissible five-second notices with CSS pixel sparkles and reduced-motion support in a reserved space above the playfield, keeping controls unobstructed. The journal fixes the background page while open, restores its scroll position on close, accounts for safe areas, and keeps Close visible while scrolling. A versioned LocalStorage save validates data, filters unknown/duplicate IDs, recovers safely from corruption, and tolerates unavailable storage. Discovery and achievement state survive game over, reset, and refresh.

Validation: TypeScript, Oxlint, 61 Vitest tests, and production build pass. New tests exercise discoveries, duplicate prevention, collection progress, save/load and corruption recovery, achievements, restart persistence, scene events, and journal pause/resume/cleanup. Browser smoke checks verify real drop/merge unlocks, locked/discovered artwork, details selection, First Evolution, Close/Escape, pause preservation, reset, and refresh persistence. Follow-up checks at 320 × 568 portrait and 568 × 320 landscape verify modal scrolling, background scroll locking/restoration, and notice bounds without horizontal overflow or playfield overlap. Two new tests cover scroll-lock cleanup and repeated modal lifecycles. A future art pass for more distinctive high-evolution silhouettes is documented.

Limits: saves are browser/origin-local; unavailable storage retains only page-session progress. Existing players have no retrospective discovery history. Physical mobile testing remains pending. Vite retains its existing advisory for the lazy-loaded Phaser chunk. No proprietary artwork, commercial integrations, ads, monetization code, secrets, or private configuration added. Repository remains public.
